📊 İş Takip ve Süreç Yönetim Sistemi (MVC)
Bu proje, kurum içi personel görev atamalarını, iş süreçlerini ve performans takibini dijitalleştirmek amacıyla ASP.NET MVC mimarisi kullanılarak geliştirilmiştir.

🛠 Teknik Mimari
Backend: C# / ASP.NET MVC

ORM: Entity Framework (Veritabanı yönetimi için)

Versiyon Kontrol: Git & GitHub

🌟 Öne Çıkan Özellikler
Personel bazlı görev tanımlama ve durum takibi.

Proje süreçlerinin dashboard üzerinden izlenmesi.

Modern ve kullanıcı dostu arayüz tasarımı.
